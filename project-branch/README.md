# GUIDE TO MY PROJECT:
##### 1. Clone the Repo
##### 2. Open in Android Studio
###### Open Android Studio
###### Click on "Open an existing project"
###### Select the folder you just cloned
##### 3. Build & Run
###### Wait for Gradle to sync
###### Click Run
##### 4. Done!
###### The app should now launch on the emulator and be usable. At the first launch, the emulator will ask to give the permission for the app to set alarms and reminders.
###### In the case, if the app won't still launch, you need to go to Settings -> Apps -> Habit Reminder App -> click on "Alarms and Reminders" and click allow.
